# Profile 512 — Owner App

This folder holds the Owner App profile design implementation.

- Display frame label: **GIO OFFICIAL**
- Profile role: **PRIMARY RESELLER**
- Name remains outside the frame and is editable.
- Name animation changes light/colour only; letter positions remain still.
- Three separate statistic tiles: Followers, Reseller, Level.
- Black-and-gold styling; crown/diamond accents.
- Responsive sizing for mobile screens.

The scoped stylesheet is `profile-512.css`. It is intentionally isolated under `.profile512` so existing login, dashboard, and authorization code are not affected until the profile screen is wired in and tested.
